# Soundtrak AI Studio - organisation (team) edition

This repository is the **download** for setting the Studio up for a **team**: several people,
each with their own Claude Code, sharing one set of brands, one library and one set of campaigns.

## Start here

**Read the Organisation deployment guide first:** [`code/docs/guide/org-deployment-guide.html`](code/docs/guide/org-deployment-guide.html)

Download it, do not clone it: click the green **Code** button above, then **Download ZIP**.
No GitHub account is needed.

## What is in here

| Folder | Becomes | Who changes it |
|---|---|---|
| `code/` | Your organisation's **code** repository. The Studio itself. | Nobody. Everyone takes a new version when they choose to. |
| `data/` | Your organisation's **data** repository. Campaigns, brands, libraries. | Everyone, through Claude Code. Nobody types a command. |

The deployment guide walks you through creating those two private repositories inside your own
organisation and uploading these folders into them. It takes about 30 minutes, once.

## Setting it up for yourself alone?

Use the single-person edition instead: <https://github.com/abraun64/soundtrak-ai-studio>.
It is simpler, and nothing in this repository applies to you.
